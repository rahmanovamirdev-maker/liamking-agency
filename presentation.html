1 О проекте

LIAMKING AGENCY — полнофункциональная веб-платформа для управления кадровым агентством. Система обеспечивает полный цикл работы: от поиска кандидатов до их трудоустройства.

Ключевые возможности

📋 Управление анкетами

Создание, направление и обработка анкет кандидатов (модели и операторы)

👥 Командная иерархия

Сквады → Команды → Скауты. Полное управление структурой

📱 БД Лидов

Пул лидов, массовая загрузка, касания, распределение между скаутами

💬 Внутренний чат

Чат по каждой анкете между участниками процесса

📊 Аналитика

Статистика по сквадам, агентам, конверсия, топ-рейтинги

🏆 Геймификация

Достижения, прогресс-бары, таблица лидеров

🔔 Уведомления

Мгновенные уведомления со звуком при важных событиях

📰 Новости

Лента новостей с закреплёнными постами и комментариями

4 Жизненный цикл анкеты

Типы анкет

👩 Модель

Имя, возраст, телефон, Telegram, как представились, вакансия, языки, роль, Nude/No-Nude, описание, фото

🖥️ Оператор

Имя, возраст, телефон, Telegram, компания, уровень английского, опыт, характеристики ПК

Этапы обработки

1. СОЗДАНИЕ (Скаут) Скаут заполняет анкету → статус: На рассмотрении ↓ 2. НАПРАВЛЕНИЕ (Owner / Team Leader) Проверяет анкету и направляет на партнёра: → HuntMe или Mason → статус: Направлена → или Отклоняет ↓ 3. ОБРАБОТКА HR (HR HuntMe / HR Mason) HR получает уведомление и ведёт кандидата: HuntMe (модель): записана → собеседование → регистрация → активна HuntMe (оператор): записана → собеседование → обучение Mason: игнор → собеседование → регистрация ↓ 4. РЕЗУЛЬТАТ ✅ Регистрация / Активен — кандидат трудоустроен ❌ Отказ — с указанием причины ⚠️ Не пришёл / Игнор — собеседование не состоялось
💡 Важно: На каждом этапе скаут получает уведомление об изменении статуса. К каждой анкете привязан чат для коммуникации между участниками.

5 Командная иерархия

🏢 СКВАД (возглавляет Squad Admin / Owner) │ ├── 👥 КОМАНДА 1 │ ├── Лидер: Team Leader │ ├── Скаут 1 │ ├── Скаут 2 │ └── Скаут 3 │ ├── 👥 КОМАНДА 2 │ ├── Лидер: Team Leader │ ├── Скаут 4 │ └── Скаут 5 │ └── 👥 КОМАНДА 3 ├── Лидер: Admin └── Скаут 6

Раздел «Моя Команда» (для Team Leader)

  • Сводка по скваду: всего анкет, зарегистрировано, отклонено, конверсия, активных скаутов
  • По каждой команде: лидер, участники, статистика
  • По каждому скауту: ФИО, последняя анкета, общие метрики
  • Фильтр по периоду: день, неделя, месяц, год, всё время

Раздел «Команды» (общий)

  • Иерархическое дерево всех сквадов и команд
  • Owner/Team Leader могут создавать сквады и команды
  • Назначение лидеров и добавление участников

6 База данных лидов

Для Owner

📦 Пул лидов

Нераспределённые лиды, доступные для назначения скаутам

📤 Загрузка

Массовый импорт лидов из CSV/TXT (имя, телефон, Telegram, источник)

👆 Касания 1-4

Отслеживание попыток контакта: 1 (жёлтый) → 2 (оранжевый) → 3 (красный) → 4+ (мусор)

➕ Создание

Ручное добавление лидов (имя, телефон, Telegram, источник)

Для Скаута / Admin

  • Мои лиды — список назначенных лидов с возможностью менять статус
  • Статусы лида: Новый → В работе → Связался → Обработан / Отказ / Игнор
  • Запрос лидов — скаут может запросить дополнительные лиды у Team Leader
  • История заявок — статус: ожидает / одобрена / отклонена (с комментарием)

Для Team Leader

  • Заявки на лиды — одобрение/отклонение запросов скаутов
  • Просмотр скаутов — статистика по лидам каждого скаута
  • Назначение лидов — распределение из пула

7 Направления: HuntMe и Mason

⚡ HuntMe

Доступ: Owner, Team Leader, HR HuntMe

Статусы модели:

Записана → Собеседование → Регистрация → Активна

Не пришла / Игнор / Отказ

Статусы оператора:

Записан → Собеседование → Обучение / Отказ

💎 Mason

Доступ: Owner, HR Mason

Статусы (модель и оператор):

Игнор → Собеседование пришёл → Регистрация

Не пришёл / Отказ

Панель Куратора

Куратор видит две группы анкет:

  • Записанные — ожидают собеседования
  • На собеседовании — кандидат пришёл, ожидается решение

Архив

  • Таблица всех анкет с пагинацией (по 50 на странице)
  • Поиск и фильтрация по статусу
  • Owner может удалять анкеты безвозвратно

8 Аналитика и достижения

Статистика

📊 Общая

Всего анкет, зарегистрировано, отклонено, конверсия %. Разбивка по статусам.

🏢 По сквадам

Таблица: сквад, анкеты, регистрации, отклонения, конверсия

🏆 Топ агентов

Рейтинг лучших скаутов за выбранный период

👤 Личная

Анкеты, регистрации, результаты за неделю/месяц/год

Система достижений

Категория Описание Примеры
🎯 Анкеты По количеству созданных анкет 5, 25, 100, 500 анкет
⭐ Регистрации По успешным регистрациям Первая регистрация, 10, 50 регистраций
🔥 Лиды По обработке лидов 10, 50, 200 обработанных лидов
🏅 Активность По стрикам и вовлечённости 7 дней подряд, 30 дней активности

Включает прогресс-бары и таблицу лидеров — топ-10 пользователей по достижениям.

9 Коммуникация

Чат по анкете

👥 Участники

Скаут, Админ, Куратор, HR — все, кто привязан к анкете. Owner видит все чаты.

📎 Файлы

Отправка изображений (превью) и документов (PDF, Word) до 5 МБ

🔄 Обновление

Автоматическое обновление каждые 5 секунд. Группировка по датам.

🎨 Роли в чате

Каждый участник отмечен цветной меткой роли для удобства

Уведомления

Событие Кто получает
Скаут создал анкету Team Leader сквада
Анкета направлена на HuntMe/Mason Скаут + все HR этого направления
HR изменил статус анкеты Скаут
Новое сообщение в чате Все участники анкеты (кроме отправителя)
Скаут запросил лиды Team Leader
Заявка на лиды одобрена/отклонена Скаут
🔔 Звук: При поступлении нового уведомления прозвучит мелодичный двойной тон. Счётчик непрочитанных отображается в боковом меню рядом с «Уведомления».

10 Администрирование

Admin Panel (Owner / Team Leader)

👤 Пользователи

Создание, редактирование, деактивация. Назначение ролей (множественный выбор), привязка к скваду/команде.

🏢 Сквады

Создание сквадов, назначение Squad Admin, редактирование.

📰 Посты

Создание новостей, закрепление постов, удаление. Видны всем на главной.

📋 Логи

История всех действий в системе для аудита и контроля.

Профиль (для всех)

  • Просмотр: ФИО, роли, сквад, команда, дата регистрации
  • Статистика: анкеты, регистрации, за неделю/месяц
  • Редактирование: ФИО, описание о себе, кошелёк для выплат (TRC20)
  • Безопасность: смена пароля (минимум 6 символов)
